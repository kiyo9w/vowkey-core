# Store listings

## Chrome Web Store Limited Use

Vowkey's use of information received from Google APIs follows the Chrome Web Store User Data Policy, including the Limited Use requirements. The extension does not sell user data, use it for advertising, or use it to decide creditworthiness. Usage counts and crash reports leave the extension only after the person turns the matching switch on. A crash report contains the error, its stack, the app version and the operating system. It does not contain a page address, a field value, or vault contents.

## Firefox

The manifest sets `data_collection_permissions.required` to `none` and `optional` to `technicalAndInteraction`. The extension requests that optional permission only when the person turns on usage counts or crash reports.
