# Reporting a Security Issue

If you find a security vulnerability in Vowkey, email **security@vowkey.app** with steps to reproduce and the affected client or service version. Details on Vowkey's security model and reporting process are published at [vowkey.app/#security](https://vowkey.app/#security).

## Responsible Disclosure

- Report vulnerabilities privately to **security@vowkey.app** so we can investigate and ship a fix before public disclosure.
- Test only against accounts, vaults, and infrastructure you own or have explicit permission to test.
- Avoid denial-of-service testing, automated abuse, or social engineering against Vowkey users and staff.
