# Vowkey Send

This folder contains 2 packages that can be used to create and modify Sends.

## semd-core

Package name: `@vowkey/send-core`

Contains all types, models, and services for Vowkey Send

Currently in use by the Vowkey Web Vault, CLI, desktop app and browser extension

## send-ui

Package name: `@vowkey/send-ui`

Contains all UI components used for Vowkey Send
